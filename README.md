# Oracle Car Service Center Management System

An Oracle database-backed system for a car service center to manage customer and vehicle records, service visits, spare-parts inventory, car washing, and billing.

## Features
- Customer and vehicle management
- Job cards with status transitions and odometer validation
- Spare-parts inventory with automatic stock updates and low-stock retrieval
- Invoice generation (service, parts, and wash totals, discounts, 14% VAT)
- Role-based login flow
- Prevention of updates/deletes on closed job cards

## Tech Stack
Oracle Database 11g, SQL, PL/SQL, Oracle Forms 10g, Oracle Reports

## Project Structure
- `/sql` : tables, constraints, sequences, triggers
- `/plsql` : packages (customers/vehicles, job cards, stock, car wash, invoices, payments, login)
- `/forms` : Oracle Forms files
- `/screenshots` : application screens
